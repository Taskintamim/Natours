## 🌄 Project Overview

**Natours** is a sleek, modern, and visually compelling landing page built using **HTML**, **CSS**, and **JavaScript**.  
Designed to promote adventure tours and outdoor experiences, this project uses bold typography, immersive background images, and a clean UI for a stunning first impression.

---

## ✨ Features

- ✅ Fullscreen hero section with image overlay
- ✅ Modern typography & centered layout
- ✅ Custom diagonal section cut
- ✅ Interactive hamburger menu icon
- ✅ Minimalist, clean design aesthetic
- ✅ Responsive for all device sizes

---

## 🔧 Tech Stack

- **HTML5** – Structure and content
- **CSS3** – Styling, layout, and visual effects
- **JavaScript (Vanilla)** – For future interactivity
- **[Optional] Vercel/Netlify** – Hosting and deployment
